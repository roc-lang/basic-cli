# basic-cli 0.26.0-rc1

Release candidate from [PR #512](https://github.com/roc-lang/basic-cli/pull/512),
for testing the MSVC host with Roc `nightly-2026-10-11-7d256b9`.

The Windows x64 host keeps the MSVC ABI and supplies the startup/runtime inputs
required by this nightly. Native C dependencies use Zig, and generated runtime
and Windows import archives are combined into `windows_support.lib`. Original
licenses, notices and source/build provenance are included in the bundle.

The producer validates every Windows binary input and uses compiler identities
to invalidate cached native builds when Zig or its adapter changes.

Use this platform URL in your application's header:

```roc
{{PLATFORM_URL}}
```

[Download the generated docs](https://github.com/roc-lang/basic-cli/releases/download/0.26.0-rc1/docs.tar.gz).

Windows execution is tested on Server 2025 CI. Testing on clean Windows 10/11
installations without Visual C++ redistributables is still needed.
