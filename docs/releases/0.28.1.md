# basic-cli 0.28.1

```roc
app [main!] { pf: platform "{{PLATFORM_URL}}" }
```

Use Roc **`nightly-2026-11-13-03dce41`** or later. CI, release builds, and the
Nix development shell now use this nightly.

## Fixes

- `Cmd` and `Path` check without duplicate-definition warnings on the new
  nightly ([#556](https://github.com/roc-lang/basic-cli/issues/556)).
  `Cmd.Command` remains opaque and keeps all its builder and execution methods;
  the `Cmd.call!`, `capture!`, `run!`, and `spawn!` convenience functions keep
  their existing signatures.
- The pinned compiler includes the Windows unwind-table fix in
  [roc#12996](https://github.com/roc-lang/roc/pull/12996). This resolves the
  compile-time failures of quoted `Locale` and `Path` values reported in
  [#555](https://github.com/roc-lang/basic-cli/issues/555). Applications using
  0.27.0 or 0.28.0 also benefit from upgrading the compiler; their literals do
  not need changing.
- The platform header now explicitly types `main!` arguments as `List(OsStr)`,
  matching the native arguments supplied by the launcher
  ([#554](https://github.com/roc-lang/basic-cli/pull/554)).

Source validation now checks the platform with `--no-cache` on Linux and
Windows, so dependency warnings and compile-time literal failures fail CI.
Linux runtime checks use the official nightly and verify static PIE loading
and development-backend callbacks.
